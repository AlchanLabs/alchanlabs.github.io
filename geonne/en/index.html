Geonne

Geonne sends photos, videos, documents and multi-GB files between your own devices on the same Wi-Fi, with no cables. Sending many in a row never stalls, and if a transfer is interrupted, only the remaining files are sent. Files go directly between devices with no server and no account, and every connection is encrypted.

Both the sending and receiving devices must be on the same Wi-Fi with Geonne open. Only the first time you connect, you check that the same 6-digit number appears on both screens.

Install on Mac

  1. Open the downloaded file

    Double-click Geonne-1.0.0.dmg, downloaded with the button above. A small window opens.

  2. Drag Geonne into the Applications folder

    Drag the Geonne icon in the window onto the Applications folder next to it. That finishes the install. You can close the window and move the dmg to the Trash.

  3. Open Geonne from Applications

    The first time, if a notice says it is an app downloaded from the Internet, click [Open]. The app has been checked by Apple, so no other warning appears.

  4. Click [Allow] on the “Local Network” prompt

    This is required to find other devices on the same Wi-Fi. If you blocked it by mistake, turn on Geonne in System Settings → Privacy & Security → Local Network.

Install on Windows

  1. Download and open the installer

    Click [Download for Windows] above. A file named Geonne-Setup-1.0.0 is saved to your Downloads folder. Double-click it.

  2. If “Windows protected your PC” appears, click [More info] → [Run anyway]

    Because this is a small company’s program without a Microsoft certificate yet, this notice may appear the first time. Click [More info] in the window; the app name Geonne-Setup-1.0.0.exe and the publisher appear, and a [Run anyway] button shows up below. Click it.

    The window color may look blue or purple depending on your PC’s color settings.

  3. In the setup wizard, click [Next] → [Install] → [Finish]

    By default it installs for the current user only, with no administrator password. Tick the desktop shortcut if you want one. Leave [Launch Geonne] ticked on the last page and click [Finish] to start it. Next time, open Geonne from the Start menu.

  4. If a firewall window appears, click [Allow access]

    If “Windows Defender Firewall has blocked some features of this app” appears, make sure Private networks is ticked and click [Allow access]. If it is blocked, the devices cannot see each other.

Connect and send for the first time

  1. Open Geonne on both devices

    Open Geonne on two devices on the same Wi-Fi. Within a few seconds each appears in the other’s Nearby devices list.

  2. Tap [Send] next to the device and choose files

    For a device you have not connected before, the button is [Pair & send]. On Mac and Windows you can also drop files into the window. You can pick many at once, and large files go as they are.

  3. Check the 6-digit number only the first time

    Two devices meeting for the first time show the same 6-digit number on both screens. If they match, tap [They match] on both devices (the receiving button is [They match — receive]). The transfer starts, and next time you won’t be asked.

  4. Tap [Receive] on the receiving device

    When files arrive from a device you already connected, see who is sending how many files, then tap [Receive]. For your own regular devices you can turn on “Always accept” to receive without asking.

FAQ

The other device doesn’t appear in the list

Check that both devices are on the same Wi-Fi and Geonne is open on both. Some routers’ “AP isolation” and guest Wi-Fi at offices or cafés keep devices from seeing each other. In that case enter the other device’s address under [Connect by IP] on the Geonne screen. Also check Local Network permission on Mac and the firewall on Windows.

Do files go through an internet server?

No. Files go directly between devices on the same network and every connection is encrypted. There is no sign-up or login.

Can I send whole folders?

Not yet. Please zip the folder and send the zip file.

How do I get a new version?

Download the new installer from this page and install it; it installs over the old version.

How do I uninstall?

On Mac, move Geonne from the Applications folder to the Trash. On Windows, open Settings → Apps → Installed apps, find Geonne and click [Uninstall].

What about my privacy?

The Mac and Windows apps have no ads and no accounts, and files and history stay on your device. See the Privacy Policy.
